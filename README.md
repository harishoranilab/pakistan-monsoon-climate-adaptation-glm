# MonsoonGLM Pakistan Hydroclimate Reconstruction 1981–2020

This repository contains the analysis code for the manuscript:

Pakistan Monsoon Rainfall for Climate Adaptation Using Generalized Linear Models

The repository includes scripts for data preparation, predictor screening, GLM fitting, leave-one-year-out cross-validation, detrended sensitivity testing, rolling-window coefficient stability analysis, and bootstrap skill evaluation.

Raw datasets are not redistributed here. CHIRPS, ERA5, Niño-3.4, and DMI data should be downloaded from their official sources.
